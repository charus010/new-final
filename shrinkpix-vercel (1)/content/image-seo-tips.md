Search engines cannot see a picture the way people do. They rely on the clues you give them: file names, surrounding text, alt attributes, page speed and structured data. Handle those clues well and your images can bring visitors from Google Images and help the page around them rank higher. Here are the practical steps that matter most.

## Start with a descriptive file name

A file called IMG_4821.jpg tells Google nothing. A file called red-ceramic-teapot-side-view.jpg describes the subject in plain words. Use lowercase letters, separate words with hyphens and keep names short but specific. Do this before you upload, because renaming later can break links and caches. Avoid stuffing several keywords into one name; one clear description is enough and reads naturally.

## Write useful alt text

Alt text is the description shown when an image fails to load and the text that screen readers announce. It is both an accessibility requirement and a strong relevance signal. Describe what is actually in the image in a sentence or less, for example a woman repotting a fern on a balcony. Do not start with the words image of, do not repeat the same phrase on every picture and never cram keywords. Purely decorative images should have an empty alt attribute so assistive tools skip them.

## Compress and size images correctly

Page speed is a ranking factor, and oversized images are the most common reason pages are slow. Resize each picture to the largest size it will be displayed at, then compress it. A good target for most blog photographs is under 150 KB. Smaller files improve Largest Contentful Paint, one of Google's Core Web Vitals, and they keep mobile visitors from leaving before the page appears.

## Pick the right format

Use JPG for photographs, PNG for graphics needing transparency and WebP when your audience's browsers support it. Choosing the proper format reduces size without hurting quality. Our guide on comparing JPG, PNG and WebP walks through the details.

## Always set width and height

When the browser knows an image's dimensions in advance, it reserves space and the page does not jump as pictures load. That jump is measured as Cumulative Layout Shift. Add width and height attributes that match the image's real proportions, and let your stylesheet make it responsive with a maximum width of one hundred percent.

## Use responsive images and lazy loading

The srcset attribute lets you offer several sizes of the same picture so phones download a small version and large screens a bigger one. Add loading set to lazy to images below the fold so they load only when a visitor scrolls near them. Do not lazy load your main hero image, because that delays the most important visual on the page.

## Put images in context

Google reads the text around a picture to understand it. Place images near the paragraph that discusses them, add a clear caption when it helps and make sure the page's heading and title match the topic. An image with a relevant surrounding paragraph will almost always outperform the same image sitting alone in a gallery.

## Create an image sitemap and use structured data

If your images load through scripts or galleries that crawlers may miss, list them in an image sitemap or add image entries to your regular sitemap. For products, recipes and articles, structured data can make your images eligible for richer search results. Always check the result in Google Search Console to confirm the markup is valid.

## Choose original, high quality visuals

Stock photos used on thousands of sites give search engines little reason to prefer yours. Original photographs, custom diagrams and annotated screenshots are more distinctive and more likely to earn clicks and links. Make sure you own or have permission to use every image, and credit sources where required.

## Measure and improve

Open the Performance report for Google Images in Search Console to see impressions and clicks for your pictures. Run important pages through PageSpeed Insights, fix any warnings about image size or format and recheck after each change. Small, steady improvements add up.

## Summary

Image SEO is mostly careful housekeeping: descriptive names, honest alt text, correct formats, compressed files, defined dimensions and relevant context. None of it is complicated, yet few sites do all of it. Apply these habits to every image you publish and you will gain faster pages, better accessibility and a steady source of search traffic.

## Common image SEO mistakes

Typical problems include generic file names, missing or duplicated alt text, giant uncompressed files, images placed far from relevant text and pictures that are blocked from crawling by site settings. Another mistake is delivering key images only through background styles, which search engines may not treat as content. Fix these one at a time, starting with your most visited pages, and check progress in Search Console.
